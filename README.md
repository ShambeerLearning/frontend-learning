## 🚀 Запуск TypeScript файлов (only-typescript)

Для папок внутри `only-typescript` настроены команды в корневом `package.json`. Они автоматически переходят в нужную директорию и запускают файл в режиме `--watch` (автообновление при сохранении).

**Синтаксис:**

```bash
npm run <имя_команды> -- <относительный_путь_к_файлу>

```

**Доступные команды:**

* `npm run single-p -- <файл>` — запуск в `projects/only-typescript/single-proj`
* `npm run fun-p -- <файл>` — запуск в `projects/only-typescript/fun-proj`
* `npm run json-p -- <файл>` — запуск в `projects/only-typescript/json-proj`
* `npm run old-p -- <файл>` — запуск в `projects/only-typescript/old-proj`

**Пример использования:**
Чтобы запустить файл `index.ts`, который лежит в подпапке `proj1` внутри `json-proj`, выполните в корне проекта:

```bash
npm run json-p -- proj1/index.ts

```

*Примечание: Выполнение идет напрямую через `tsx`. Все импортируемые локальные файлы (например, `info.json`) должны содержать валидную структуру (минимум пустой объект `{}`).*

## 🌐 Запуск Frontend проектов (full-code-and-html)

Для управления веб-проектами используется Turborepo и встроенный механизм workspaces от npm.

**Запуск всех проектов одновременно:**

```bash
npm run dev

```

**Запуск конкретного проекта (например, только `proj1`):**
Чтобы не поднимать все серверы разом, используйте флаг `-w` (workspace) с указанием имени проекта, которое прописано в его локальном `package.json` (в поле `"name"`):

```bash
npm run dev -w proj1

```

*(Если имя проекта в его `package.json` отличается от названия папки, указывайте именно имя из конфигурации).*

**Альтернативный запуск через фильтр Turbo:**

```bash
npm run dev -- --filter=proj1

```

## 📝 Правила написания кода

* **Правильное форматирование кода:** Логика, интерфейсы и стили выносятся в отдельные файлы.
* **Изоляция:** Каждому файлу — своя функция.
* **Чистота:** Никакого мусора из хлама в основном коде. Вспомогательные блоки убираются и обрабатываются отдельно.
